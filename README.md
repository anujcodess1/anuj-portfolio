# Anuj's Portfolio

A modern, responsive personal portfolio built with React and Lenis smooth scrolling.

## 🚀 Features

- **Interactive Hero & Navigation**: Smooth navigation with custom branding and animated UI elements.
- **Experience & Journey**: Timeline showcasing developer journey and technical milestones.
- **Projects & Skills**: Showcasing full-stack and frontend development capabilities.
- **Smooth Scrolling**: Integrated with Lenis for an ultra-smooth experience.
- **Responsive Design**: Optimized across mobile, tablet, and desktop screens.

## 🛠️ Tech Stack

- **React 19**
- **JavaScript (ES6+)**
- **Lenis Smooth Scroll**
- **Vanilla CSS**

## 💻 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or yarn

### Installation
```bash
git clone https://github.com/anujcodess1/anuj-portfolio.git
cd anuj-portfolio
npm install
npm start
```
